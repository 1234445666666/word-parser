# Парсер частоты слов на C++

Консольное приложение, которое читает текстовый файл, разбивает его на слова и подсчитывает, сколько раз встречается каждое слово. Результат выводится в алфавитном порядке.

## Требования

- Компилятор C++ с поддержкой C++17 (g++ или clang++)
- Linux, macOS или Windows (с MinGW/WSL)
- Терминал

## Сборка и запуск

1. Убедись, что в папке с проектом лежит файл `main.cpp` и текстовый файл `text.txt` (или создай его).
2. Скомпилируй:
   ```bash
   g++ main.cpp -o wordcount
   ```
